<h3 align="center">Quietly breaking things since 2019.</h3>

I build data pipelines and analytics tooling in Python, leaning heavily on Pandas, NumPy, and DuckDB. Most of my work involves turning raw, inconsistent datasets into something actually useful for decision-making. I care about the infrastructure side of data — ETL design, query performance, and getting SQL and Python to cooperate cleanly.
